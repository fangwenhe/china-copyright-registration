# 中国版权登记指南（面向外国创作者/企业）

[English](../README.md) | **中文**

> 面向外国创作者、设计师、开发者和企业的中国版权登记实操指南：作品著作权与计算机软件著作权（软著）。

**为什么要在中国登记版权？** 中国著作权法规定作品自创作完成之日起自动受保护，但**自愿登记证书**是最有力、成本最低的权属证明——能显著加快天猫、淘宝、抖音、TikTok Shop 等平台的侵权下架，支撑授权交易，并在行政投诉和诉讼中形成清晰证据链。

## 核心要点

1. **社媒发帖不是有效在先证据**：抖音/小红书/X 的时间戳只能证明"某时刻存在一条公开帖子"，不能正式证明作者身份和作品完整内容，且容易被质疑（删帖、编辑、第三方工具）。登记证书才是专业、法院认可的证据。**先登记，后发布。**
2. **外国权利人可以登记**：外国个人和企业均可在中国登记作品/软著，可通过 CCPC 涉外通道或备案代理机构办理；英文材料一般需附中文翻译。
3. **海外登记不等于中国证书**：美国/欧盟的版权登记在中国不能直接用于平台投诉和海关备案，本地维权最方便的证据仍是中国登记证书。
4. **版权 ≠ 商标**：版权保护作品本身（代码、图片、文字），商标保护商业标识。品牌方通常两者都要。

## 维权与平台下架

1. **平台投诉**：天猫/淘宝、抖音、TikTok Shop、微信、京东的品牌保护/知识产权投诉平台，上传证书+侵权链接+证据，验证后通常数日内处理。
2. **行政投诉**：向地方版权局投诉盗版内容。
3. **民事诉讼**：中国知识产权法院将登记证书作为有力的初步证据。
4. **海关备案**：备案版权可在口岸拦截盗版货物进出口。
