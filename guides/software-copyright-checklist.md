# Software Copyright (软著) Registration Checklist — China

> Practical checklist for registering a **computer software copyright (计算机软件著作权, 软著)** with the China Copyright Protection Center (CCPC). Works for foreign software companies filing directly or via an agency.

## What you can register

- Original computer programs (desktop, web, mobile, embedded, SaaS)
- Software documentation (user manual, design specification)
- The program and its documentation are registered **together as one software copyright**

## Documents to prepare

### 1. Application form
- Generated by the CCPC online system after filling in software details
- Fields: software full name + version (e.g. `Acme ERP System V1.0`), completion date, first publication date (or "not published"), development method (independent/commissioned/cooperative), rights scope

### 2. Identity documents
- **Company applicant**: business license (Chinese entity) or certificate of incorporation + Chinese translation (foreign entity)
- **Individual applicant**: ID card / passport + Chinese translation
- Filing through an agency: signed/sealed power of attorney (委托书)

### 3. Source code document (源代码文档)
- **Format**: PDF, A4, first **30 pages + last 30 pages** of source code (if total ≤ 60 pages, submit all)
- Each page: ≥ 50 lines, with page header showing software name + version, page numbers
- Remove sensitive credentials, keys and third-party proprietary code; add a copyright notice line at the top
- Language: code itself stays in its programming language; headers/notes may be bilingual

### 4. Software documentation (软件说明书/用户手册)
- User manual or design document, usually 30–60 pages
- Must show: software purpose, functions, operating environment, screenshots, operation flow
- Match the submitted code's feature set (examiners compare)

## Naming rules (frequent rejection cause)

- Format: `[Brand/Function] Software [Type] V[Version]`, e.g. `Huaqing Trademark Management System V1.0`
- Avoid: generic industry terms alone ("Management System V1.0"), trademark symbols (®/™), "China/中国" prefixes without authorization
- Version starts at V1.0; minor updates V1.1; major rewrite V2.0 (new registration optional)

## Process & timeline

| Stage | Detail | Time |
|---|---|---|
| Online filing | CCPC system upload + form | 1 day |
| Formality check | Corrections requested if materials incomplete | 1–2 weeks |
| Examination | Substantive review of code/docs | 30–60 working days |
| Certificate | Electronic certificate first, paper by mail | +1–2 weeks |

- **Official fee: ¥0 (free)** for standard software copyright registration
- Agency service fee (if used): market range ¥300–1,500 depending on rush level; rush certificates available at extra cost

## Common rejection reasons (avoid these)

1. Code pages with too few lines or missing page headers/numbers
2. Manual describes features absent from the code (or vice versa)
3. Name contains another party's registered trademark
4. Obvious template/generated "hello world" code with no real function
5. Third-party open-source code presented as own work (GPL contamination disputes)

## After registration

- Certificate is **prima facie evidence of ownership** in China, valid for **50 years from first publication** (or 50 years from creation if unpublished)
- Use it for: app store appeals, Tmall/Taobao/Douyin software/listing takedowns, high-tech enterprise (高新技术企业) applications, government funding, licensing
